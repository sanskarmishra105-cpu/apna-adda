# Sanskar Mishra — Developer Portfolio

A clean, responsive personal portfolio built with HTML, CSS, and JavaScript.

## About
I'm Sanskar, an aspiring developer exploring web development, Python tools, AI/ML, and small interactive games. This portfolio is a starting point for sharing projects and documenting what I learn.

## What's inside
- Responsive portfolio landing page
- Project cards for web, Python, and game projects
- Contact links to GitHub
- No frameworks or build tools required

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open this repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.

## Customize
Update the project cards in `index.html` as you publish real projects. Keep project descriptions accurate and replace placeholder links with the relevant repositories or demos.
