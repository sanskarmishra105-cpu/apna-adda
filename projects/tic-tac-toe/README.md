# Tic Tac Toe

A responsive, two-player Tic Tac Toe game that runs in a browser. Built with vanilla HTML, CSS, and JavaScript—no frameworks or install steps required.

## Run it
Open `index.html` in any modern browser, or use the live demo linked from the portfolio after GitHub Pages deploys.

## Features
- Two-player turns (X and O)
- Detects wins across rows, columns, and diagonals
- Detects draws
- Round reset and new-game controls
- Round score tracking
- Responsive layout and accessible status announcements

## Concepts practiced
DOM selection and events, arrays, state transitions, conditionals, reusable functions, CSS Grid, responsive design, and accessibility basics.

## Project structure
- `index.html` — page structure
- `style.css` — responsive visual design
- `script.js` — game state and rules

## Try these improvements
1. Add a computer opponent.
2. Add keyboard navigation.
3. Save scores with local storage.
4. Write tests for every winning line and draw scenario.

This is a small learning project. Before presenting it in an interview, run it yourself, understand the win-checking logic, and make a few changes of your own.
