A MINI WEB GAME

Tic Tac Toe.

A classic game, built for the browser.

Player X's turn

X 0 · O 0 · Draws 0

How to play

Take turns placing X and O. First player to connect three marks in a row, column, or diagonal wins. If all nine squares fill with no winner, it's a draw.

What this project practices

  • DOM interaction and event handling
  • Game state and win-condition logic
  • Responsive layout and accessible labels
